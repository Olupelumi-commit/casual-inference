#SMS nudge RCT Analysis -One Acre Fund Nigeria (2017)
A full casual inference analysis of a 7-arm randomised controlled trial testing whether SMS nudges increase smallholder farmer program qualification rates in Nigeria.
Techniques: Intent-to-treat estimation. Chi-Square significance testing. Logistic Regression. Subgroup heterogenixity analysis . Operational Impact project

Dataset: 462,885 farmers . 7 Treatment arms. 2 Outcomes
